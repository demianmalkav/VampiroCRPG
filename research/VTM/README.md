# VTM 3e System Extraction

Purpose: translate Vampire: The Masquerade 3rd Edition concepts into explicit CRPG design requirements without silently changing the source material.

## Extraction template
For each concept:
- Source concept
- Source framing / purpose
- Tabletop rule or narrative function
- Desired player experience
- Candidate CRPG system
- State variables
- Events
- Dependencies
- Failure cases / ambiguities
- Status: SOURCE_ONLY / PROPOSED / APPROVED / IMPLEMENTED

## Initial topics
- Personal horror
- Traditions
- Blood
- Humanity
- Beast / Frenzy
- Clans
- Disciplines
- Domain and hospitality
- Masquerade
- Political structure
- Damage / combat implications
- Character creation

Do not treat interpretations as source facts. Clearly separate extraction from proposed adaptation.
